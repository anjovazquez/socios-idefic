# VS-027 — Patrocinadores por temporada (admin)

Status: TODO
Milestone: 0.7 Comunidad
Refs: RF-026, RF-027, RF-028, RN-016

## Goal

El admin gestiona patrocinadores y los asocia a temporadas.

## In scope

- `sponsors` (club_id, name, logo_path, website_url, is_active) y `sponsor_seasons` (sponsor_id, season_id, unique).
- UI admin: alta/edición (nombre, logo, web validada https), activar/desactivar, asociar/desasociar temporadas, "Renovar para la temporada activa" en bloque.

## BDD

```gherkin
Feature: Patrocinadores

  Scenario: Alta y asociación
    When doy de alta "Restaurante X" con logo y web y lo asocio a 2026/2027
    Then aparece como patrocinador de 2026/2027

  Scenario: No pasa solo a la nueva temporada
    Given Restaurante X patrocinó 2026/2027
    When se activa 2027/2028
    Then no es patrocinador de 2027/2028 hasta que lo renueve

  Scenario: Desactivar
    When desactivo Restaurante X
    Then deja de mostrarse a los socios aunque esté asociado a la temporada
```
