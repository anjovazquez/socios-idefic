# VS-029 — Ventajas (admin)

Status: TODO
Milestone: 0.7 Comunidad
Refs: RF-024, RN-015

## Goal

El admin publica ventajas sencillas para socios, opcionalmente ligadas a un patrocinador.

## In scope

- `perks` (club_id, sponsor_id nullable (mismo club), title, body, image opcional, valid_from, valid_until, status `draft|published|archived`).
- UI admin: alta, edición, publicación, archivado.
