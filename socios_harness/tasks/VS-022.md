# VS-022 — Método de pago guardado para renovaciones

Status: TODO
Milestone: 0.6 Pago real y renovación automática
Refs: RF-012

## Goal

El socio puede dejar guardado un método de pago (tarjeta o domiciliación SEPA) para futuras renovaciones.

## In scope

- `payment_methods` (club_membership_id, provider, provider_customer_id, provider_method_id, kind, last4/brand o IBAN enmascarado, is_default, mandate_id para SEPA). Nunca datos completos.
- Casilla "Usar este método para renovar automáticamente" en el pago; alta de método sin pago (setup).
- Mi suscripción: ver/cambiar/eliminar método; estado "Renovación automática activada".

## BDD

```gherkin
Feature: Método de pago guardado

  Scenario: Guardar al pagar
    When Marta paga y marca "renovar automáticamente"
    Then su suscripción muestra la tarjeta terminada en 4242 y la renovación automática activada

  Scenario: Eliminar método
    When Marta elimina el método
    Then la renovación automática se desactiva

  Scenario: Domiciliación SEPA
    When Marta guarda una cuenta bancaria y acepta el mandato
    Then ve el IBAN enmascarado como método de renovación
```
