# VS-033 — CI/CD y entorno staging

Status: TODO

Refs: -

## Goal

Pipeline que despliega la web y las migraciones/funciones a staging bajo aprobación explícita.

## In scope

- Workflow con `workflow_dispatch` para: build web + hosting (por decidir: Firebase Hosting como Xogalle o Cloudflare Pages), `supabase db push` y `functions deploy` a staging, APK debug opcional.
- Secretos documentados en `DEPLOYMENT.md` (los configura el usuario): Supabase access token, Google OAuth, proveedor de email (D-013), proveedor de pago en modo test.
- `deploy-migrations` depende de `sql-tests`.

## BDD

```gherkin
Feature: Despliegue a staging

  Scenario: Despliegue autorizado
    Given CI en verde en main
    When se lanza el despliegue manual
    Then la web y las migraciones quedan en staging
```

## Notes

Nunca desplegar sin aprobación del usuario.
