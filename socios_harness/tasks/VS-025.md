# VS-025 — Blog: publicar (admin)

Status: READY
Milestone: 0.7 Comunidad
Refs: RF-022, §16 Blog

## Goal

El admin crea, edita, publica y retira noticias para sus socios.

## In scope

- `posts` (club_id, title, body (markdown simple), image_path opcional, published_at, status `draft|published|archived`, author_id).
- Bucket privado `post-images` (lectura solo miembros del club).
- UI admin: listado, editor (título, texto, imagen, fecha de publicación, permite programar a futuro), publicar/archivar.

## BDD

```gherkin
Feature: Publicar en el blog

  Scenario: Publicar noticia
    When publico "Asamblea de socios" con texto e imagen
    Then aparece publicada con la fecha de hoy

  Scenario: Borrador
    When guardo una noticia como borrador
    Then los socios no la ven

  Scenario: Publicación programada
    When programo una noticia para mañana
    Then los socios no la ven hasta mañana (hora del servidor)
```
