# VS-012 — Temporadas: crear, activar con cuota, histórico

Status: TODO
Milestone: 0.3 Temporadas y cuotas
Refs: RF-007, RF-008, RN-008, RN-009

## Goal

El admin crea temporadas, activa una con su cuota ordinaria y consulta las anteriores.

## In scope

- `seasons` (club_id, name "2026/2027", starts_on, ends_on, default_fee_cents, status `draft|active|closed`). Índice único parcial: una `active` por club.
- RPC `activate_season(season_id, default_fee_cents)`: cierra la activa anterior y activa la nueva de forma atómica; exige cuota ≥ 0.
- UI admin: listado de temporadas, crear (nombre sugerido según la última), activar con cuota, ver anteriores.
- El socio ve la temporada activa en la portada.

## BDD

```gherkin
Feature: Temporadas

  Scenario: Crear y activar temporada
    Given IDEFIC tiene activa la temporada 2026/2027
    When creo la temporada 2027/2028 y la activo con cuota 50 €
    Then 2027/2028 es la única temporada activa
    And 2026/2027 queda como anterior

  Scenario: Solo una activa
    When dos activaciones ocurren a la vez
    Then solo una temporada queda activa

  Scenario: Cuota obligatoria
    When activo una temporada sin cuota
    Then veo "Indica la cuota de la temporada"

  Scenario: Nombre duplicado
    When creo otra temporada "2027/2028" en IDEFIC
    Then veo un error
```
