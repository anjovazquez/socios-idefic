# VS-021 — Proveedor de pago real (checkout + webhook)

Status: TODO (requiere ADR-001 ACCEPTED y claves de test)
Milestone: 0.6 Pago real y renovación automática
Refs: §9, RF-015

## Goal

El socio paga su cuota online con el proveedor elegido y el estado llega por webhook.

## In scope (asumiendo Stripe, ajustar a ADR-001)

- Onboarding del club como cuenta conectada (enlace desde Configuración; estado de la cuenta guardado).
- Edge Function `create-checkout` (crea sesión de pago para un `payment` pendiente, en la cuenta del club).
- Edge Function `payments-webhook` (firma verificada, idempotente por evento) que pasa el pago a `paid`/`failed`.
- Adaptador `StripePaymentGateway` detrás de `PaymentGateway`; el manual sigue disponible.
- Botón "Pagar ahora" en Mi suscripción.

## BDD

```gherkin
Feature: Pago online

  Scenario: Pago con tarjeta
    Given Marta tiene 50 € pendientes
    When paga con una tarjeta de prueba válida
    Then el pago queda "Pagado" tras el webhook y Marta es socia activa

  Scenario: Tarjeta rechazada
    When paga con una tarjeta rechazada
    Then el pago queda "Fallido" y puede reintentarlo

  Scenario: Webhook repetido
    When el proveedor reenvía el mismo evento
    Then el pago no se procesa dos veces

  Scenario: Webhook falso
    When llega un webhook sin firma válida
    Then se rechaza
```
