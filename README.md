# Socios IDEFIC

Plataforma web y app para gestionar socios, temporadas, cuotas, pagos, carnet
digital, patrocinadores, ventajas y blog privado de clubes de baloncesto
amateur. Primer club: IDEFIC (2026/2027).

- Especificación funcional: [`docs/PROPUESTA_FUNCIONAL_MVP.md`](docs/PROPUESTA_FUNCIONAL_MVP.md)
- Plan por fases: [`socios_harness/PRODUCT_AND_ARCHITECTURE_PLAN.md`](socios_harness/PRODUCT_AND_ARCHITECTURE_PLAN.md)
- Backlog: [`socios_harness/BACKLOG.md`](socios_harness/BACKLOG.md)
- Instrucciones para agentes: [`AGENTS.md`](AGENTS.md)

Stack: Flutter 3.35.1 (FVM) + Supabase (Auth, Postgres/RLS, Edge Functions).
